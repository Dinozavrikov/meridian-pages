Техническая архитектура

Как устроен Meridian под капотом и как запустить его локально.

Стек технологий

Компонент Технологии
Frontend Next.js (React), TypeScript
Backend FastAPI (Python 3.12), SQLAlchemy, Alembic
Базы данных PostgreSQL + pgvector, Redis
AI / ML Ollama (локальные модели)
Инфраструктура Docker Compose, Caddy

Данные и локальный AI

Безопасность интеллектуальной собственности — приоритет для Meridian. Все задачи обработки естественного языка выполняются на вашем оборудовании:

  • Векторный поиск: Расширение pgvector позволяет хранить эмбеддинги текста и искать по ним прямо в PostgreSQL.
  • Локальная модель: Ollama используется для перевода, классификации и анализа. Данные не отправляются в облачные сервисы (OpenAI, Anthropic и др.).

Быстрый старт

Требования: Docker и Docker Compose v2.

git clone https://github.com/Dinozavrikov/Meridian.git
cd Meridian

cp .env.example .env
cp docker-compose.override.example.yml docker-compose.override.yml

# Генерация секретов (пример для Linux)
sed -i "s|^SECRET_KEY=.*|SECRET_KEY=$(openssl rand -hex 32)|" .env
sed -i "s|^POSTGRES_PASSWORD=.*|POSTGRES_PASSWORD=$(openssl rand -hex 16)|" .env

docker compose up -d --build

Интерфейс: http://localhost:3000. API: http://localhost:8000.
