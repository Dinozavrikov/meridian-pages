Техническая архитектура

Как устроен Meridian под капотом, какие технологии используются и почему они были выбраны.

Общая архитектура

Meridian построен с использованием контейнеризации (Docker). Это позволяет развернуть весь проект локально одной командой. Система разделена на несколько независимых сервисов:

  • Frontend: Отвечает за интерфейс пользователя, отрисовку графа и взаимодействие с API.
  • Backend (API): Основная логика, аутентификация, управление сущностями (наблюдения, гипотезы, лаборатории).
  • Базы данных: Реляционная БД для основных данных и векторная для поиска.
  • Очередь задач: Для фоновой обработки (например, генерация эмбеддингов или проверка прогнозов).

Технологический стек

Мы используем проверенные технологии, которые обеспечивают высокую производительность и надежность.

Компонент Технологии
Frontend Next.js (React), TypeScript
Backend FastAPI (Python 3.12), SQLAlchemy, Alembic
Базы данных PostgreSQL + pgvector (для эмбеддингов), Redis
AI Ollama (локальные модели)
Инфраструктура Docker Compose, Caddy

Данные и локальный AI

Важная особенность Meridian — отказ от внешних AI-сервисов (таких как OpenAI или Anthropic). Все задачи, связанные с обработкой естественного языка, решаются локально:

  • Векторный поиск: Благодаря расширению pgvector в PostgreSQL, мы можем хранить и искать по эмбеддингам текста прямо в базе данных.
  • Локальная модель: Для перевода, классификации и описания изображений используется Ollama. Это обеспечивает полную конфиденциальность данных — они не покидают ваш сервер.

Без запущенного Ollama приложение работает, но функции, связанные с AI, будут недоступны.

Запуск локально

Для запуска вам понадобятся Docker и Docker Compose v2.

# 1. Клонируйте репозиторий
git clone https://github.com/Dinozavrikov/Meridian.git
cd Meridian

# 2. Подготовьте окружение
cp .env.example .env
cp docker-compose.override.example.yml docker-compose.override.yml

# 3. Сгенерируйте секреты (пример для Linux)
sed -i "s|^SECRET_KEY=.*|SECRET_KEY=$(openssl rand -hex 32)|" .env
sed -i "s|^POSTGRES_PASSWORD=.*|POSTGRES_PASSWORD=$(openssl rand -hex 16)|" .env

# 4. Запустите контейнеры
docker compose up -d --build postgres redis backend frontend

Интерфейс будет доступен по адресу http://localhost:3000, API — по адресу http://localhost:8000.

Безопасность

  • Шифрование: Приватные сообщения шифруются в базе данных. Резервные копии также зашифрованы.
  • История изменений: Каждое действие логируется. Удаленные данные попадают в корзину и могут быть восстановлены.
  • Открытый код: Любой может проверить, как работает система, и убедиться в отсутствии скрытой передачи данных третьим лицам.
