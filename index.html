Добро пожаловать в Meridian

Meridian — это корпоративный стандарт для проверки гипотез и совместного принятия решений на основе данных. Инструмент для тех, кто хочет не просто спорить, а находить истину.

Открыть приложение → Репозиторий на GitHub

Философия проекта

Мы живём в мире мнений. Каждый день мы сталкиваемся с утверждениями, которые кажутся верными, но не имеют под собой реальной основы. Споры часто превращаются в соревнование громкости, а не логики.

Meridian предлагает другой путь. Вместо того чтобы сразу показывать идею миру, мы предлагаем сначала проверить её. Записать наблюдения, сформулировать гипотезу, сделать предсказание и отследить, сбудется ли оно.

Архитектура системы

Meridian построен на основе микросервисной архитектуры, оптимизированной для локального развертывания и обеспечения максимальной приватности. Система состоит из трех основных слоев:

  • Слой представления: Next.js приложение (SSR/SPA), обеспечивающее отзывчивый интерфейс и работу с графом.
  • Слой бизнес-логики: FastAPI (Python 3.12), обрабатывающий запросы, управляющий доступом и оркестрирующий работу AI-моделей.
  • Слой данных: PostgreSQL с расширением pgvector для векторного поиска, а также Redis для кэширования.

Технологический стек

Уровень Технологии
Frontend Next.js, React, TypeScript
Backend FastAPI (Python 3.12), SQLAlchemy, Alembic
Базы данных PostgreSQL (с pgvector), Redis
AI / ML Ollama (локальные модели, без внешних API)
Инфраструктура Docker Compose, Caddy (Reverse Proxy)

Быстрый старт (Разработка)

Для запуска проекта локально вам понадобятся Docker и Docker Compose v2. Ollama опционален и нужен только для AI-функций.

# 1. Клонируйте репозиторий
git clone https://github.com/Dinozavrikov/Meridian.git
cd Meridian

# 2. Настройте переменные окружения
cp .env.example .env
cp docker-compose.override.example.yml docker-compose.override.yml

# 3. Сгенерируйте секретные ключи (пример для Linux)
sed -i "s|^SECRET_KEY=.*|SECRET_KEY=$(openssl rand -hex 32)|" .env
sed -i "s|^POSTGRES_PASSWORD=.*|POSTGRES_PASSWORD=$(openssl rand -hex 16)|" .env

# 4. Запустите контейнеры
docker compose up -d --build postgres redis backend frontend

После запуска приложение будет доступно по адресу http://localhost:3000.

Безопасность и Конфиденциальность

В корпоративной среде безопасность данных стоит на первом месте. В Meridian реализованы следующие механизмы:

  • Шифрование данных: Приватные сообщения шифруются на уровне базы данных (AES). Резервные копии также зашифрованы.
  • Локальный AI: Все процессы обработки естественного языка (NLP), включая эмбеддинги и перевод, выполняются локально через Ollama. Данные не передаются в OpenAI или другие облачные сервисы.
  • Аудит: Каждое действие в системе логируется. Удаленные данные перемещаются в корзину и могут быть восстановлены администратором.
